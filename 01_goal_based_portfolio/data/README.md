# Datos

Carpeta reservada para los datos del proyecto. Aún no se han seleccionado ni descargado fuentes.

Para cada serie, documentar proveedor, URL, fecha de descarga, período, frecuencia, unidades, ajustes, tratamiento de faltantes y licencia. Distinguir precios de retornos totales y magnitudes nominales de reales. Versionar datos únicamente cuando la licencia lo permita; en los demás casos, documentar cómo reproducir su obtención.
